# Visualization Style Guide

This guide documents the visual conventions used across the RNAseq-Templates notebooks and the `RNAseq_lib` helper functions.

## Theme

All publication-grade plots use `theme_publication()` defined in `RNAseq_lib/plot_utils.R`. It is based on `ggplot2::theme_bw()` with:

- Grid lines removed for a clean look.
- Black panel border, axis lines, and ticks.
- Bold axis titles and plot titles (centered).
- Sans-serif font by default; manuscripts can switch to `"Times"` for some enrichment figures.

## Color Palette

The `RNAseq_PALETTE` list in `RNAseq_lib/plot_utils.R` centralizes the main colors:

| Usage | Color | Hex |
|-------|-------|-----|
| Up-regulated / Activated | Red-orange | `#d6604d` |
| Down-regulated / Suppressed | Blue | `#4393c3` |
| Not significant / neutral | Grey | `#999999` |
| Heatmap up | Dark red | `#b2182b` |
| Heatmap down | Dark blue | `#2166ac` |
| Heatmap midpoint | White | `#f7f7f7` |
| 2-group comparison (1st group) | Grey | `#6F6F6F` |
| 2-group comparison (2nd group) | Orange | `#E07B54` |
| 3rd group (if present) | Purple | `#6D65A3` |

Group colors are generated by `make_group_colors()`. For more than 3 groups it falls back to `RColorBrewer::Set1`.

## Figure Sizes

| Plot type | Default width (in) | Default height (in) |
|-----------|--------------------|----------------------|
| PCA, sample distance | 7 | 6 |
| Volcano | 8 | 10 |
| DEG heatmap | 10 | variable (0.22 × n_genes + 3) |
| Top variable genes heatmap | 8 | 10 |
| Enrichment dotplot | 8 | 10 |
| Enrichment barplot | 8.5 | 6 |
| Bidirectional barplot | 16 | 10 |
| GSEA NES barplot | 9.5 | 8 |
| compareCluster dotplot | 10 | 12 |
| Single-gene bar plot | 5.5 | 6 |
| KM plot | 7 | 8 |

These defaults can be overridden in each `*_pdf()` helper.

## Output Format

- All figures are saved as editable PDFs.
- Where available, `save_pdf_plot()` uses `cairo_pdf` for anti-aliasing; otherwise it falls back to `pdf()`.
- ComplexHeatmap / pheatmap / Mfuzz / survminer plots manually open a `pdf()` device and call `dev.off()`.

## Empty Results

Plot helpers return `invisible(NULL)` when there are no significant terms or genes, and now print a `message()` explaining why the plot was skipped. This keeps notebooks running smoothly while making empty results transparent.

## Modifying the Style

To apply a project-wide style change, edit `RNAseq_PALETTE` and `theme_publication()` in `RNAseq_lib/plot_utils.R`. For per-figure tweaks, pass `base_size` or `base_family` to the helper functions.
